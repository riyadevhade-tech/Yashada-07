# 🏆 AI Sport Performance Analyzer

## 📌 Project Overview

AI Sport Performance Analyzer is a Python and Machine Learning based
system designed to analyze sports player performance and fitness.

The system calculates player performance scores, analyzes fitness,
compares players and provides AI-based performance predictions.

## 🎯 Objectives

- Analyze player performance
- Calculate performance scores
- Analyze player fitness
- Compare players
- Identify top performers
- Predict future performance using Machine Learning
- Provide AI-based recommendations

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit
- Machine Learning
- CSV Dataset

## ⭐ Main Features

1. Player Performance Analysis
2. Fitness Analysis
3. Performance Score Calculation
4. Top Player Identification
5. AI Performance Prediction
6. AI Recommendations
7. Interactive Dashboard
8. Data Visualization

## ▶️ How to Run

Install required libraries:

pip install pandas numpy matplotlib scikit-learn streamlit

Run analysis:

python analysis/performance_analysis.py

Generate charts:

python visualizations/charts.py

Train AI model:

python models/performance_model.py

Start dashboard:

streamlit run dashboard/app.py

## 🤖 Machine Learning

Random Forest Regression is used to predict player performance score
based on performance and fitness parameters.

## 📊 Output

The dashboard provides:

- Total Players
- Average Performance
- Average Fitness
- Top Performer
- Performance Charts
- Fitness Charts
- AI Prediction
- AI Recommendations
